# Frequência de projetos

Carregue `orientacao_frequencia` no MCP Sabichão antes de planejar ou enviar frequências. Alternativa: recurso `suap://orientacoes/frequencia`.

Se o MCP não estiver conectado, leia a fonte única neste repositório: `src/sabichao/skills/sabichao-frequencia/SKILL.md`. Não invente registros nem envie dados sem prévia e confirmação.
